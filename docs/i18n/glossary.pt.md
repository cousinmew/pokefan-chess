## Notes for the native reviewer

- **Pokémon world names stay in English**, as in the Brazilian releases of the games: Pokémon, moves (Harden), places (PALLET TOWN, VIRIDIAN CITY, MT. MOON, POWER PLANT, VICTORY ROAD, INDIGO PLATEAU, CERULEAN CAVE), items (OLD AMBER, Poké Ball), trainer and character names. Gyms are written "GINÁSIO DE PEWTER". ROUTE 1 kept in English too; please check whether "ROTA 1" reads better.
- **queen = dama**, the formal chess term (CBX/FIDE usage), kept consistent everywhere including the Yellow lessons for ages 4 to 7. Many Brazilian children say "rainha"; the reviewer should decide whether Yellow/Path should use "rainha".
- **Team Rocket = Equipe Rocket**, following the Brazilian anime dub ("A Equipe Rocket está decolando de novo!"). TEAM RED became "EQUIPE RED" for symmetry. "Red vs Rocket" subtitle unchanged.
- **Trainer classes and badges**: no single authoritative pt-BR source for Gen 1 (the games were only localized into Portuguese from Scarlet/Violet). Choices: JOVEM, MOÇA, CAÇA-INSETOS, CAMPISTA, PIQUENIQUEIRA, CRIADOR DE AVES, MOTOQUEIRO, APOSTADOR, SUPERNERD, PESCADOR, NADADOR, TREINADOR ÁS, ELITE DOS QUATRO, CAMPEÃO, LENDÁRIO, CIENTISTA, RECRUTA ROCKET. Badges follow the anime dub style ("INSÍGNIA DA ROCHA", "INSÍGNIA DA CASCATA"...). Hall of Fame = "Hall da Fama".
- **Other game terms**: fainted = desmaiou; super effective = supereficaz; shiny = brilhante; candy = doce(s); sticker book = álbum de figurinhas; Trainer Card = Cartão de Treinador; Trainer Rating = Pontuação de Treinador; Trainer Level = Nível de Treinador; save = progresso (save code = código de progresso).
- **Gender with placeholders**: "Seu {piece}" / "seu {mover}" assume masculine, which fits Pokémon names (o Pikachu) but not if the placeholder ever receives a piece role like "dama" or "torre". review.pin / review.skewer were phrased to avoid agreement.
- "RED apagou!" for "RED blacked out!" is a guess at the game phrasing; please check.
