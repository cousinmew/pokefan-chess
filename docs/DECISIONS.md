# Decisions

- S1: G2 ignores the SVG namespace string `http://www.w3.org/2000/svg`; it is an identifier, not a network URL.
- S1: no ffmpeg on the build rig, so cries ship as `.ogg` only for now; fetch-assets transcodes to `.mp3` when ffmpeg exists.
- S1: captures apply instantly with a `battle.fainted` line until the S2 overlay; teaching caption keys added as `caption.*` in strings.
- S1: `__kc.stage()` reuses the start position, which already shows all 14 species with bishops on both colours.
- S1: `__kc.step()` only counts frames until S2 adds stepped animations; quiet move slides use WAAPI.
- S2: FxRecipe gains optional `actor(t)` for lunges, dashes and digging; the spec shape had no way to move the attacker.
- S2: harness adds `runBattle(a, d)` for the 98 pair sweep; `dumpState` adds `fxSig`, a hash of RNG draws used by effects.
- S2: Quick mode skips the evolution sequence (no overlay by definition); the text lines still show.
- S2: interim header toggles for Anim (Full/Quick/Off) and Sound until the S4 settings screen; not persisted yet.
- S2: cries play via `<audio>` with `preservesPitch=false` for the faint pitch drop; no `fetch` (G2).
- S3: no `stockfish.worker.ts` wrapper; the Stockfish lite build is itself a worker, loaded from `engine/` on the first level 2+ request.
- S3: interim header Mode button (Two Players, vs 4 levels), human always plays Red until S4 team select. Stockfish is GPL-3.0, combinable with AGPL-3.0 (GPLv3 §13).
- S3: T-2 (cold engine load to first bestmove at Gym Leader, 200 ms movetime) measured 492 ms headless on the dev Mac, so about 290 ms to load.
- S4: the boot gate's "board root" is now `#app .stage` (the splash shows first); the board itself is checked by every flow test.
- S4: interim header Mode/Anim/Sound buttons removed; the game header is Menu, turn, Take back. `?debug=1&start=two` skips the splash for tests.
- S4: T4 says the battle is about 1.9 s, but the §4.5 timings sum to 2.74 s (2.34 s without an effectiveness line); §4.5 ships, T4 is in the taste list.
- S4: G6 skips binary files (wasm, images, audio); the Stockfish wasm contains the byte run "aDs" by chance.
- fix: battle sprites are preloaded after the splash and the overlay inserts the decoded Image elements themselves (a fresh src refetches when the cache is off); wait capped by BATTLE.spriteWaitMs.
- T4 (owner, 2026-10-05): battle shortened to 1.9 s with an effectiveness line (1.62 s without); §4.5 steps scaled by 0.69, effects now BATTLE.fxMs.
- Owner, 2026-10-05: the battle screen is player-perspective, as in Gen 1: the player's Pokémon is always near (back view) and the opponent's far (front view), whoever attacks. Two Players: the side that just moved is near.
- Owner, 2026-10-05: PokeAPI's black-white animated back/19.gif is Alolan Rattata; fetch-assets takes the Showdown animated back sprite for #19 instead. The other 13 backs were checked by eye.
- Mobile fix: prefers-reduced-motion no longer switches battles to Quick (no overlay); it keeps Full and drops shake and flashes. Settings saved by v1 with Quick are reset once (settings `v: 2`).
- WebKit iPhone 13 project runs tests tagged @webkit (capture battle, with and without reduced motion); WebKit showed no other failure.
- Castling: tapping the king then its own rook castles toward that rook; the king's dots already showed g1/c1 (g8/c8).
- O1: relay = Worker + SQLite-backed Durable Object (free plan), hibernating WebSockets, state in DO storage, one alarm for the 60 s reconnect deadline and 24 h room expiry.
- O1: the per tab session token is mirrored in localStorage per room so a closed and reopened tab resumes its seat; the same token from a new tab takes the seat over (the old tab sees "carried on in another tab").
- O1: no trainer names yet (V3 allows a fixed list; nothing to show without them). Online screens live in src/ui/online.ts, not src/ui/screens/online.ts, matching the existing layout.
- O1: G2 now allows fetch/WebSocket only in src/net/, and config.ts absolute URLs only for the repo, Discord and RELAY_URL. Local tests run the relay on :8788 with a 5 s reconnect window.
- Domain: pokefanchess.com via public/CNAME and the Pages API. Vite base stays './' (relative), which already serves from the domain root and from the old github.io path alike. Relay allows https and http pokefanchess.com.
- Relay accepts HTTPS origins only; local tests add http://localhost:4173 via --var.
- The cd587b2 push event reached Actions about 10 min late (runs created 22:39 UTC, after the next commit), a GitHub-side delay. Deploy now also skips any commit that is no longer the tip of main. Deploy now runs only after ci succeeds on main (workflow_run), and ci gains workflow_dispatch for a manual rerun.
- FX: recipes drawn at FX_SCALE 2 with dark outlines; a 120 ms full screen flash tinted by move type (TYPE_COLORS) replaces bolt's white flash; none under reduced motion. `?debug=1&gallery=fx` plays all 14; `npm run sheets` rewrites docs/fx-sheet/ and docs/sprite-sheet.png.
- Music: 6 cues; public/audio/<cue>.mp3 is used when present at build time (vite define), else an original procedural chiptune. Loops play from decoded buffers (MUSIC_LOOPS), so G2 lets src/audio/music.ts fetch its own same origin files. One Music slider (default 30%) covers the loops; stings follow the sound effects slider.
- C1: 18 Lichess themes from Part B §B2 (all present), 8,035 puzzles, 921 KB; one puzzle may sit in several theme files. Built once by scripts/build-puzzles.mjs from ~/Code/pokefan-chess-data/ (outside the repo, never committed), decoded with fzstd (no system zstd).
- C1: Trainer Rating is Glicko-2 starting at 600 / RD 350 / vol 0.06, tau 0.5, RD floor 45; puzzles are assumed RD 75. A solve after a hint is recorded but leaves the rating unchanged. Puzzle order is seeded per visit from the clock (no Math.random).
- C2: one tall grass route before each B2 stop (Route 1, Viridian Forest, Routes 3, 6, 7, 14, 8, Sea Route 21, Route 22), each with that stop's Lichess themes; tables are Red, walk method, from PokéAPI (scripts/build-kanto.mjs, `npm run kanto:check` re-fetches and diffs). Until C3's gyms, route N+1 opens when route N is mastered (8 of last 10 solved; a hint solve counts).
- C2: capture moves are the species' first damaging Red/Blue level-up move with Gen 1 type and power from past_values; Gen 1 types are the earliest past_types entry. Move type maps to one of the 14 FX; the effectiveness chart still covers only the v1 types, so new types show no effectiveness line.
- C2: skins override the species per role and colour; vs Computer applies My Team to your side, online sends it in `join` and the relay passes both in `state` (validated role keys and id shape). Every Gen 1 species with an Alolan form takes the Showdown back sprite.
- C2b story (§B11): src/data/journey.kanto.json (schema in schemas/journey.schema.json, checked with ajv; kept out of src/ because its $schema id is an absolute URL, G2) holds places, 21 route trainers and 3 rival fights; every line is original and lives in strings.en.json. A trainer is 3 puzzles (win 2), BLUE is 5 puzzles over every theme learned so far (win 3) and leads with the starter strong against yours. Gyms stay placeholders that never block until C3. Plain Puzzles left the title menu (Training replaces it); the harness keeps `openPuzzles()` for tests.
- C2b data (§B12): build-kanto.mjs adds Blue tables, all 151 species, 72 Gen 1 evolutions (later generation babies dropped from chain roots), the 151 source map (every Kanto area, Red and Blue, any method, plus planned C3 sources) and Gen 1 type relations; PokéAPI responses are cached in ~/Code/pokefan-chess-data/pokeapi/ and `--check` always re-fetches. Tall grass rolls Red or Blue at even odds.
- C2b collection: candy 3 per catch and 1 per duplicate sent to Oak, evolving costs 25 / 50 (the evolved catch does not add its own candy), shiny 1 in 64 or on a 5 first try streak, stars at 3 / 6 / 10 duplicates. Skin ids carry variants as name[:s][:1-3]; the relay accepts that shape. Saves migrate from v1 to v2 keeping every catch: candy for past catches, caught counts as seen, a mastered C2 route counts as cleared.
- C2b types: the chart now covers all 15 Gen 1 types (Ghost 0 vs Psychic, Bug and Poison 2x each way) and a unit test checks all 225 pairs against PokéAPI.
- C2c starter picker "empty boxes": not reproducible on the live site in Chromium or WebKit (the GIFs load). The likely cause on a phone is the 28 battle GIF preload queued ahead of the starters on a slow connection. Fix: every menu sprite shows its tiny Gen 1 sprite as a background until the GIF loads, falls back to it on error, and starters load at high priority; the cards no longer overflow at 360 px. tests/e2e/visuals.spec.ts checks naturalWidth on every such screen.
- C2c trainer sprites come from Pokémon Showdown at build time (src/data/trainers.json maps people and classes; camper and picnicker use the Gen 2 set, Cooltrainer uses Gen 3's Ace Trainer, the same class). A missing sprite falls back to a CSS silhouette.
- C2c lessons: each route trainer teaches one of the route's themes in turn; the rival is "everything so far". A lesson's example is the easiest puzzle of that theme with 3 or more moves, its first 3 moves looped on a board of Gen 1 sprites. Lessons show once per theme and reopen from Training.
- C2c team rules: shared in worker/src/team.ts (data in worker/src/species-rules.json, generated by build-kanto.mjs). Single stage species (e.g. TAUROS) count as first stage for pawns and as eligible for rooks, knights and bishops. The relay cannot see a player's starter or badges, so it accepts any starter family as king and treats the queen as unlocked. Saves get teamRules: 1 once, with ineligible slots reverted and listed in a one time notice.
- C3 quick fix: saves created before C2c keep the queen slot open (grandfathered, `queenOpen`). A save counts as pre C2c when it has a starter but no `introSeen` (C2c's Oak intro sets it before the starter). Team rules v2 also gives back an eligible queen that C2c reverted, if it is still listed in the notice.
- C3 gyms: each leader is 5 puzzles, win 4, on that gym's B2 themes; winning gives the badge in a ceremony and gyms now block the places after them. A place cleared before C3 stays open, so no one loses progress made while gyms were placeholders.
- C3 rewards (§B12 part 2): beating BLUE the first time gives the starter neither of you picked, the second time BLUE's own; Eevee at Celadon gym; Lapras plus a Hitmonlee or Hitmonchan choice at Saffron gym; Magikarp plus an Omanyte or Kabuto choice at Mt. Moon; Porygon from a Game Corner prize set; Aerodactyl at Cinnabar Lab; Zapdos (Power Plant), Articuno (Seafoam), Moltres (Victory Road peak) and Mewtwo (Cerulean Cave, after the Champion) from puzzle sets 150 to 300 points above your level. Side places are optional and never block. Rewards are given once per place.
- C3 Victory Road: K+Q vs K within 15 moves, then K+R vs K within 25 (generous for this audience), the lone king defended at level 3. A stalemate or running out of moves fails and retries.
- C3 Elite Four: Lorelei (skewer), Bruno (x-ray), Agatha (mixed +100), Lance (mixed +200), each 5 puzzles win 4; a loss retries that member, not the whole League. Champion BLUE is a full game at level 1 to 4 from your Trainer Level (<800, <1100, <1400, above); journey games use default teams (§B14). The Hall of Fame shows your starter and My Team.
- C3 trade evolutions fire on any online win (checkmate, resign or timeout) for trade species on your team; Mew is given when the map shows with 150 others caught.
- C4 review moment (§B15): every puzzle ends in a review that waits for Continue (Journey trainers, rival, gyms, Elite Four, Training, tall grass, plain puzzles). Solved: the final position, the line replayed once at REVIEW_MOVE_MS with green arrows, then the theme's key idea (fork, pin, skewer, discovered attack, mate, hanging piece, promotion; other themes arrows only) and a template line. Wrong: your move in red, Stockfish's reply (level REFUTATION_LEVEL, the existing worker; any legal capture if the engine fails) in blue at OPPONENT_REPLY_MS, a template line, then Show answer. Battles and tall grass act only on Continue; the old TRAINER_NEXT_MS and ENCOUNTER_PAUSE_MS timers are gone. The puzzle's own replies now play at 900 ms.
- C4 gyms 1 to 4 need 3 of 5 (GYM_NEED_EARLY), gyms 5 to 8 keep 4 of 5 (GYM_NEED_LATE), in config.ts; journey.kanto.json mirrors them and a unit test keeps the two equal.
- C4 the full gym walk e2e is tagged @slow: playwright skips it unless CI is set, so CI runs it before every deploy (deploy waits for ci) and the local gate does not.
- C5 hub (§B16): the title screen became the hub in place (same test ids). Continue resumes whatever was last ("last" in storage: the journey map at its furthest place, or the saved game), the mini Trainer Card opens the full one, and Pokédex, My Team, Trainer Card and Training open straight from the hub and return to it. Tooltips appear only on hover capable screens 900 px and wider and only rephrase the subtitle. Settings, Share and Trainer Card have no "?" (not modes).
- C5 manual: How to Play is an 8 page booklet (journey, training, battle, computer, two, online, pieces, catching) reusing the lesson's mini board (now exported with any position), the flamethrower FX recipe and the team legend. "Try it" for Your Pieces opens My Team; for Battles & Catching, the Journey. `npm run sheets` also writes docs/hub/.
- C5 addendum (§B16): the hub is one column at every width with 32 px between zones; tiles carry no mascots and never bounce (press feedback is a slight darken plus the blip). Icons: PokeAPI item sprites fetched at build time into assets/items/ (town map, Teachy TV, Poké Ball, VS Seeker, card key, TM for How to Play and every "?", Oak's parcel; credited) shown 2x; original 16 px pixel art SVGs in src/ui/icons.ts for Two Players, Online, Pokédex, My Team and Settings, shown 3x (the 29 px row of six Poké Balls at 2x). Oak appears once, static, in the Journey header.
- C6 cartridges (§B17): first launch shows the shelf (two original CSS cartridges, YELLOW and BLUE, and a language picker in each language's own name); the choice is remembered in "cartridge", and Settings switches it with a 2 s press and hold (CARTRIDGE_HOLD_MS). Both share one save. With storage blocked nothing can be remembered, so the shelf shows every launch. Tests start as a returning BLUE player (playwright storageState).
- C6 YELLOW: home of three tiles (Play vs Youngster as RED with Pikachu, Learn, Friend) and a gear; glyphs always on, take back always, one text line and no captions, no effectiveness lines, gentle end lines, Quick battles the first time (YELLOW_DEFAULT_ANIM), bigger squares. Pikachu's Path: lessons 1 to 9 are authored (the six pieces, then capturing, check and escaping check, because mateIn1 puzzles cannot teach those), 10 to 12 use mateIn1 puzzles under 800. Each finished lesson gives one guaranteed sticker from Route 1 or Viridian Forest (the game has no Route 2 table). The sticker book is the Pokédex shown as stickers, opened from the Path.
- C6 i18n: strings.<lang>.json per language with English fallback; species and move names come from PokéAPI for fr and es (generated into names.<lang>.json; es move names differ from English, e.g. PLACAJE, so B17's "es matches English" did not hold for moves), English elsewhere. Hebrew sets dir="rtl", wraps every inserted value in U+2068/U+2069, and keeps the board, mini boards and review layer left to right. Translations were drafted by three parallel agents and are marked for native review (PLAYTEST-NOTES).
- B18 item 1 room code: likely causes of "the field does not work": maxlength 4 cut a pasted code or link before it could be cleaned, an invalid code only refocused the field with no message, there was no form (the phone's Go key), and WebKit ignores the autocapitalize property. Now: the field is a form (Enter, Go and Join submit), hints are set as attributes (inputmode, autocapitalize, autocomplete, autocorrect, spellcheck, enterkeyhint), input is normalised as you type (letters only, upper case, a pasted link's code, first 4), a short code says so, a code with I or O (never issued) says "no such room" instead of dialling the relay, and ?room= links in any case join and prefill. Tests tagged @both run in Chromium and WebKit; Android is Pixel 7 emulation in Chromium.
